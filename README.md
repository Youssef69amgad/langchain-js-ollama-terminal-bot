# LangChain JS Terminal Bot with Ollama

A simple terminal chatbot built using LangChain JS and Ollama.

## Features

- Uses LangChain JS
- Runs locally with Ollama
- Uses a simple RAG-like flow
- Retrieves relevant context from a small knowledge base
- Answers questions about LangChain JS

## Project Flow

User Question → Retriever → Context → Prompt Template → Ollama Model → Answer

## Requirements

- Node.js
- Ollama
- llama3.2:3b model
